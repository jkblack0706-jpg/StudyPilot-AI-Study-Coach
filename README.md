# StudyPilot — AI Study Coach

Python FastAPI web app for studying with Planner, Tutor, Quiz Maker and Reviewer agents. See the StudyPilot source ZIP for all application files, tests, LaTeX report, and Render configuration.

**Deployment:** source files must be added before building on Render. Do not commit `.env` or any Gemini API keys.
